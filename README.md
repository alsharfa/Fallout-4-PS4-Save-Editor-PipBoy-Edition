# Fallout 4 PS4 Save Editor PipBoy Edition

## Features

- Player name editing.
- Linked **Level + XP** editing with automatic progression synchronization.
- Persistent **Player Health** editing.
- One-click **Unlimited Player Health** preset: `999,999,999`.
- Persistent **Player AP** editing.
- Persistent **Player Carry Weight** editing.
- One-click **Unlimited Player Carry** preset: `999,999,999`.
- Companion detection.
- Companion carry-weight overrides.
- SPECIAL stat editing.
- All 70 vanilla SPECIAL perk groups.
- Real inventory quantity editing.
- Add items by category: Weapons, Apparel, Aid, Misc, Junk, Mods and Ammo.
- Weapon add, change and remove workflow by name.
- Weapon OMOD editing.
- Apparel OMOD editing.
- Legendary effect editing.
- **Two Shot Gauss Rifle** workflow.
- One-click **BEST GEAR** preset.
- Stored statistics editing.
- Global workshop statistics editing.
- Verified quest stage and objective editing.
- Undo / Redo.
- Pending-change review.
- Structural save validation.
- Automatic backups.
